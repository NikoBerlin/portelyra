# Handbuch

Das Handbuch gehört zur installierten Version und steht in jeder App unter **Hilfe** (links im Block unter der Navigation). Ein zweiter Klick auf **Hilfe**
schließt es wieder, ebenso **Schließen** oder die Esc-Taste. Ein **?** neben einer Karte springt zum passenden Abschnitt.

## Zum Einstieg

- [Erste Schritte](erste-schritte.md) – einmal am Demo-Portfolio durch: einrichten, Kurse, Verlauf, eine Buchung, ein Import,
  Steuerbericht, Backup.
- [Installation](installation.md) und [Update einspielen](update.md)
- [Das Demo-Portfolio](demo.md)

## Die vier Apps

- [Data](app-data.md) – hier entstehen alle Daten: Buchungen, Stammdaten, Kurse, Steuerangaben. Die einzige App, die schreibt.
- [Cockpit](app-cockpit.md) – worauf gerechnet wird: Stände, Konten, Kurse, Belege, Einstellungen.
- [Steuer](app-steuer.md) – Steuerreport, Jahresrechnung, Rechenblätter und Unterlagen je Jahr.
- [Analyse](app-analyse.md) – Verlauf, Rendite, Vergleich, Stichtag und Momentaufnahme.
