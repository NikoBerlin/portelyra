# Guided Asset Center v1

The owner-only Data app presents one resumable Asset process over separate Catalog, Provider Mapping, Tax Policy, Daily History and Asset Activity domains.

Required first step: an existing active Asset or one separately confirmed Asset Catalog create command. An existing Asset's canonical business price currency has its own explicit revision-bound Preview/Confirm/Execute path and remains separate from Provider currency. Provider, Tax, Market History and initial Activity remain optional dimensions and never become implicit prerequisites for realized calculations.

The browser receives only labels and session-local refs. Every write-capable domain retains its own preview, confirmation, owner and recovery semantics. The Asset Center is not a distributed transaction and does not roll back already committed prior steps. Its Activity handoff visibly opens and focuses the single-target command form, initializes a separate one-Asset browser presentation scope and filters the FIFO/custody/history read tables, but performs no Activity write. The presentation scope can later contain multiple Assets without creating batch-write authority. Browser `NULL` clears nullable filter operands instead of retaining hidden refs, and the explicit full filter reset restores read-only defaults without changing that single Activity target.

Since [ADR-205](../../../docs/decisions/ADR-205-scoped-batch-review-and-data-workspace-navigation.md) the five main tabs are Transaktionen (manual, imports, drafts and corrections), Stammdaten, Marktdaten (Provider plus single History and multi-Asset completion), Steuer and Abschluss. Inputs are composed once, not remounted on navigation. Explicit Provider name search also works before Asset creation; applying a selected candidate only fills editable form proposals. A supplied formally valid ISIN may fill a blank ISIN, never overwrite manual input. The sidebar reports the last action on desktop and mobile, not a global readiness guarantee. Existing names/ISIN use native Catalog correction previews. Independent persistent Provider and master-data worklists keep stable private Asset identities and unconfirmed drafts, with explicit pause/resume, skip/defer and next-item control; see [Desktop Asset Worklists](../../desktop-asset-worklists/v1/README.md). No navigation or completed mapping automatically fetches History. Unknown Provider currency is visibly proposed as USD, never silently confirmed; saved mappings take precedence. Non-provider valuation methods do not show artificial Provider requirements.

Provider search/test controls default to inactive. No page load, refresh, selection, planning or mapping write starts a Provider. Daily History uses two visible one-use confirmations: one bounded fetch into an owner-local sealed candidate, then—only after exact table/plot review—publication of that exact candidate without refetch, or terminal rejection without a Market write. Recovery reconciles a consumed attempt before any retry. Live external execution and productive publication each remain separately authorized operations. Missing Tax/Provider/History data remains visibly unavailable or partial, never zero.
