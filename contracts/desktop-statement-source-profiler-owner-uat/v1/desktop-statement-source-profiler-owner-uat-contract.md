# Contract

Selection reads metadata only. Authorization is consumed and sealed before exactly one `O_NOFOLLOW` read. ADR-164 profiles those bytes in memory. The native review may observe or reject the structure while disabled. Evidence contains hashes, counts, decisions, and negative capabilities only. A consumed attempt has no retry authority. Attempt-only history blocks pending explicit recovery.

The boundary does not use `kraken_ledger_csv_source_v1:r1` as a parse precondition and does not create `r2`. Unknown or ambiguous structures remain blocked. No source path, raw header, raw token, row value, source bytes, Candidate, ActivityDraft, Catalog, Cash, Tax, SQL, Provider, network, activation, release, or deployment effect is authorized.
