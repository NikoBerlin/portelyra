# Contract

Every unknown column receives an explicit owner role or `explicit_nonsemantic_evidence`; every semantic tuple receives one closed disabled route. Decimal and exact local-zone decisions are complete. Output contains hashes, counts and decisions but no raw header or semantic token. Row counts close exactly with `silent_drop_count=0`. The overlay cannot activate, create Candidates, create a Git profile revision, or write Product, Cash, Tax or Canonical state.
