# Desktop FX Pair Probe v1

A provider-free preview binds one Yahoo currency candidate, demanded source/target currencies, explicit direct or inverse semantics and at most 32 calendar days. Exactly one confirmation authorizes one chart request. Normalized evidence is persisted owner-locally before any schema-2600 Pair or FX History write.

The probe has no Pair-binding, FX-History, canonical, conversion, retry, fallback or publication authority. A later separately confirmed promotion must consume the exact staged result without Provider refetch.
